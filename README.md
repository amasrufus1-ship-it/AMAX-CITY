# AMAX CITY Android starter

This is an Android Studio starter project for the AMAX CITY blue-and-white messaging app.

## Open it
1. Download and unzip this project.
2. Open the `amax_city_android` folder in Android Studio.
3. Let Gradle sync finish.
4. Run on an Android emulator or connected phone.

## Included in this prototype
- Login / create-account screen (demo only)
- Chat list with search
- Local demo conversation screen with message entry
- Groups tab placeholder
- Profile tab and demo logout
- Blue-and-white AMAX CITY styling

## Important limitations
This is a UI prototype, not a production messaging service. Login is not authenticated, messages are only held locally during the app session, group creation is not connected, and voice notes/calls are visual placeholders. A secure backend, database, real account verification, media storage, push notifications, and properly implemented encryption are needed before real users can communicate.
